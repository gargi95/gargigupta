# Gargi Gupta - PhD Portfolio Website

A professional, high-performance portfolio website showcasing my research in **Explainable Artificial Intelligence (XAI)**, academic publications, and industry experience.

The site features a modern "Light Lavender" aesthetic, interactive carousels, and a unique dual-view resume system designed to engage both academic peers and industry recruiters.

## 🛠️ Technical Stack

* **Frontend:** HTML5, CSS3 (Custom Variables, Flexbox, Grid)
* **Interactivity:** Vanilla JavaScript (Intersection Observer API, ES6+)
* **Typography:** Playfair Display (Headings), Poppins (Body)
* **Icons:** Font Awesome 6.5.1
* **Forms:** Formspree Integration for serverless contact handling

---

## ✨ Features

* **XAI Focused Branding:** Tailored content emphasizing my work with LSTMs, SHAP, and symbolic state-transition representations.
* **Dual-View Timeline:** An interactive toggle allowing users to switch between a horizontal **Ticker View** (for quick scanning) and a vertical **List View** (for detailed reading).
* **Smart Typing Animation:** A dynamic header that cycles through my professional identities (PhD Researcher, Data Scientist, ML Engineer).
* **Research Spotlight:** Dedicated sections for my Science Foundation Ireland (SFI) funded research and conference presentations (AICS, PyLadies, etc.).
* **Serial Hobbyist Section:** A customized "Beyond Research" carousel showcasing my life as a Taekwondo blue belt and gardener.
* **Fully Responsive:** optimized for seamless viewing across mobile, tablet, and desktop devices.
